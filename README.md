MindEdge - Backend API
This repository contains the backend infrastructure for MindEdge, built with a focus on performance, security, and scalable architecture.

 Live Demo & API Testing
The API is deployed and ready for testing. You can explore and trigger the endpoints through the Swagger UI:
   https://midedge.runasp.net

Technical Stack
Framework: .NET 10 (ASP.NET Core)

Language: C#

Database: SQL Server (Remote Hosting via Monster ASP)

Authentication: JWT (JSON Web Tokens)

Documentation: Swagger / OpenAPI
